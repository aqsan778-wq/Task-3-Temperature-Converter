# Task 3 - Temperature Converter

A simple Temperature Converter web application built using HTML5, CSS3, and JavaScript.

## Features

- Convert temperature between Celsius, Fahrenheit, and Kelvin
- Displays all three temperature values
- Input validation
- Responsive and user-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `index.html` - Website structure
- `style.css` - Styling and design
- `script.js` - Temperature conversion logic

## How to Use

1. Enter a temperature.
2. Select the temperature unit.
3. Click the Convert button.
4. View the converted values.
